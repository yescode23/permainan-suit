# Game Suit - Batu Gunting Kertas

## Fitur
- Pilihan interaktif: Batu, Gunting, Kertas
- Komputer memilih secara acak
- Tampilan hasil menang / kalah / seri
- Gambar ikon menarik untuk setiap pilihan

## Teknologi yang digunakan
- HTML5 – Struktur halaman
- CSS3 – Desain dan tata letak
- JavaScript (DOM) – Logika permainan dan interaksi

``` bash
git clone https://github.com/yescode23/game-suit.git
```

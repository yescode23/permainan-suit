Game Suit - Batu Gunting Kertas

Proyek sederhana berbasis JavaScript, HTML, dan CSS yang meniru permainan klasik Batu, Gunting, Kertas.
User dapat memilih salah satu opsi, lalu komputer akan memilih secara acak — hasil permainan langsung ditampilkan di layar.

Fitur

Pilihan interaktif: Batu, Gunting, Kertas
Komputer memilih secara acak
Tampilan hasil menang / kalah / seri
Gambar ikon menarik untuk setiap pilihan

Teknologi yang digunakan
HTML5 – Struktur halaman
CSS3 – Desain dan tata letak
JavaScript (DOM) – Logika permainan dan interaksi

Cara Menjalankan
Clone repositori ini:
git clone https://github.com/yescode23/game-suit.git
Masuk ke folder proyek:
cd game-suit
Buka file index.html di browser.
